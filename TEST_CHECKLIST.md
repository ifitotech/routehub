# RouteHub — Checklist de pruebas

## Acceso y privacidad
- [ ] Manager autorizado puede entrar.
- [ ] Email no autorizado es rechazado.
- [ ] Usuario solo ve su empresa.
- [ ] Driver solo ve su ruta.
- [ ] Counter Sales no puede administrar usuarios.

## Contactos y solicitudes
- [ ] Crear y editar contacto.
- [ ] Autocomplete completa dirección.
- [ ] Crear Pickup y Delivery.
- [ ] Cambiar prioridad y estado.
- [ ] Asignar solicitud a una ruta.

## Rutas
- [ ] Crear borrador.
- [ ] Añadir y reordenar paradas.
- [ ] Publicar ruta.
- [ ] Cambiar driver.
- [ ] Modo bloqueado y flexible.

## Driver
- [ ] Comenzar ruta.
- [ ] Abrir navegación.
- [ ] Completar con GPS.
- [ ] Completar con foto fuera de rango.
- [ ] Reportar local cerrado.
- [ ] Ver siguiente parada.

## Reportes y operación
- [ ] Activity log registra cambios.
- [ ] Reportes filtran por empresa.
- [ ] Fotos/firmas respetan retención.
- [ ] Funciona en móvil y escritorio.
- [ ] `npm.cmd run typecheck` pasa.
- [ ] `npm.cmd run build` pasa.
