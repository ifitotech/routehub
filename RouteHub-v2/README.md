# RouteHub v2

Nueva implementación independiente de RouteHub. La versión actual permanece intacta.

## Principios

- Interfaces separadas por rol (CEO, Manager, Operations, Counter Sales y Driver).
- Inglés por defecto; Español y Français desde Settings.
- Rutas individuales de pickup, delivery, transfer y return.
- Supabase con RLS, GPS, evidencia, firma y soporte offline.
- Driver mobile-first; escritorio optimizado para despacho.

Esta carpeta se implementará gradualmente y no se publicará hasta pasar typecheck, lint, build y pruebas funcionales.
