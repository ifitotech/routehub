# RouteHub v2 functional checklist

## Access

- [ ] CEO can open all workspaces.
- [ ] Manager can manage routes, branches and team.
- [ ] Operations can dispatch but cannot manage platform companies.
- [ ] Counter Sales can create requests and contacts.
- [ ] Driver sees only mission, history and settings.

## Missions

- [ ] Create pickup.
- [ ] Create delivery.
- [ ] Create transfer.
- [ ] Create return to branch.
- [ ] Assign a team member.
- [ ] Reorder pending missions.
- [ ] Block completed missions.
- [ ] Insert urgent mission.

## Driver

- [ ] Start mission.
- [ ] Open navigation.
- [ ] Validate GPS distance.
- [ ] Complete within the allowed radius.
- [ ] Complete with photo override.
- [ ] Report closed location.
- [ ] Save signature.
- [ ] See the next mission automatically.
- [ ] Queue actions offline and sync later.

## Data and security

- [ ] Contact is linked to the mission.
- [ ] Evidence is stored in a private bucket.
- [ ] Company isolation works with RLS.
- [ ] Audit activity is recorded.
- [ ] Revoked invitations cannot authenticate.
